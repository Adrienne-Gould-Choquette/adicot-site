Load calculations are the foundation of every mechanical design. Get them wrong and
the equipment is wrong, the ductwork is wrong, and the energy model built on top of
them is wrong. We produce stamped load calculations that hold up in plan review.

## What you get

- Room-by-room cooling and heating loads
- Ventilation rates to the governing code for the jurisdiction
- Equipment sizing recommendations, with the assumptions written down
- A stamped, plan-review-ready document

## Methodology

**The building code governs.** The first authority on any project is the state or
local building code adopted in that jurisdiction. It sets the design conditions, the
ventilation requirements and which standards apply. Where it references an ASHRAE
standard, we work to the edition the code references, not the newest one
published.

**Load calculations.** Commercial load calculations follow ASHRAE methods.

**Ventilation.** Rates follow whatever the adopted code requires. That is commonly
ASHRAE Standard 62.1, but not always. Some jurisdictions and occupancies point to a
different standard, and specialty work can be governed by something else entirely.
The ventilation rate for a utility control enclosure, for instance, is set by the 1%
hydrogen concentration limit (25% of hydrogen's lower flammable limit; IEEE 484 and
IFC §1207.6.1.1, formerly §608), not by an occupancy table.

**Inputs.** Envelope assemblies, glazing, occupancy, lighting and equipment loads come
off the drawings and the project's code, not from defaults. Where an assumption is
unavoidable, it is stated on the output so the reviewer can see exactly what the
number rests on.
